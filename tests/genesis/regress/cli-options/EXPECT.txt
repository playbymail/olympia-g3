exit 1
-- stdout
-- stderr
genesis-g3: invalid option -- x
Usage: genesis-g3 [--seed N] [--size 10..99] [--number-of-oceans N]
          [--island-iterations 2..10] [--defer-oceans]
          [--ocean-growth frontier|bfs]
          [--start-cities 0..16]
          [--image FILE.bmp] [--pixels 1..64] [--grid 0..4]
  --number-of-oceans is capped to min(ceil(size/3), 12) and clamped to
  fit; larger requests are reduced with a warning.
  --defer-oceans generates the oceans AFTER the islands and Mt. Olympus
  (origin-seeded, size-named; largest sea = Great Sea).  See issue #80.
  --ocean-growth picks how --defer-oceans grows each ocean from its
  origin: frontier (default; random frontier flood, ragged seas) or bfs
  (ring-by-ring, nearest origin through the water).  See issue #87.
  --start-cities places up to N safe-haven start cities on land (default
  6; fewer if they can't be spaced; 0 = none).  Without at least one,
  olympia-g3 can't add players.  See issue #85.
  --image dumps the generated Map as a 24-bit BMP for eyeballing the
  world (debug aid, issue #81; emitted only when given, never affects
  the Map/Regions/Land/Cities output).  --pixels sets N x N pixels per
  province (default 8); --grid sets black grid-line thickness in pixels
  between and around provinces (default 0 = no grid).
Generates the mapgen input set (Map, Regions, Land, Cities, randseed)
in the current directory.  See doc/genesis.md.
