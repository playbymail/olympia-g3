# Authors & Credits

## Original game

Olympia was created by **Rich Skrenta** (Copyright 1993 — the original sources
are public domain). The G3 engine in this repository is the third-generation
Olympia play-by-mail strategy game engine — the GitHub-era version with
refinements over G2, and the ancestor of the TAG engine.
